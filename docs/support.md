# Wrap Guide Support

## Quick help

- Use a regular rectangular box with all edges visible.
- Place it on a flat, uncluttered table in even light.
- Move the iPhone slowly and keep the box inside the guide.
- Confirm the measured dimensions before cutting paper.
- If scanning is unstable, choose **Enter dimensions manually**. Paper planning and every wrapping step remain available.
- If an overlay drifts, tap **Relock box**. You do not need to measure the box again.

## Supported in version 1.0

- iPhone, portrait orientation
- Rectangular or nearly rectangular boxes
- Rectangular wrapping paper
- One standard long-seam wrapping method
- On-device processing

Irregular objects, bottles, cylinders, gift bags, ribbons, social features, and cloud sync are not supported.
